如何安装更新

  1. 下载 RBZ 后，在 SketchUp 的“扩展程序管理器”选择“安装扩展程序”，打开下载的 RBZ。
  2. 安装前保存模型；安装完成后重启 SketchUp，再检查当前版本。

下载按钮在浏览器中打开 GitHub 下载地址。此处不会直接替换正在运行的插件。
