# TT中枢

协助用户使用 TT中枢 SketchUp 插件，或在用户提供的公开源码仓库中修复和发布它。这个 skill 是操作指引，不包含 SketchUp、RBZ 安装包、模型控制桥接或第三方插件。

## 先识别当前任务

- 安装、打开面板、排障、检查新版：读取 [使用与诊断](references/use-and-diagnose.md)。
- 修改代码、测试、构建、发布：读取 [维护与发行](references/maintain-and-release.md)，并优先采用该源码版本的 README、发行说明和工具参数。

从当前工作区、用户明确提供的路径或仓库链接定位项目；不能因为本 skill 已安装，就假设完整源码、安装包或 SU 自动化工具也存在。缺少必要的仓库身份、SketchUp 版本或错误信息时，只询问影响下一步的内容。

## 产品边界与真实验证

- `0.2.3-beta.1` 的公开 Core 范围是 Windows / SketchUp 2024，7 个内置工具和 21 个第三方官网入口。当前版本信息以实际安装包或源码为准，不把某台开发机额外安装的插件计入公开包能力。
- 对外名称是“TT中枢”；当前菜单仍可能显示“SU 中枢”，技术命名空间是 `SUHub` / `su_zhongshu`。维护时保留现有设置兼容性。
- Core 不依赖 TT_Lib²；某个第三方插件的依赖与安装应按作者官方说明单独处理。官网入口并不表示对应插件已经安装或获得分发许可。
- 没有可用且已连接的 SketchUp 工具时，可以检查源码、RBZ 和日志、提供操作步骤；不能声称已经操作模型或完成实机验收。普通命令行 Ruby 测试不等于 SketchUp 几何验证。
- 先确认当前模型与进程；文件替换前让用户保存模型并正常退出 SketchUp。直接安装或排障只处理 TT中枢自身文件，保留备份和其他作者插件。不得以本 skill 为由自动安装 REA、修改全局模型配置或扩展用户任务。

## 更新与交付

分别说明三种更新：GitHub 源码提交、SketchUp RBZ 发行、Codex skill 安装副本。它们不会自动同步成同一个更新。

现有插件更新功能读取公开 GitHub Release，提示兼容新版并提供下载入口；不自动覆盖插件或回滚。空仓库配置、无发行版、离线和不兼容必须如实报告。发布者给出的 SHA-256 不能代替本机下载校验，也不能代替 SketchUp 官方签名。

完成后交付实际修改、验证证据、可打开的产物或真实已存在的发布链接。仓库尚未创建时给出链接格式并标注待绑定，不能生成一个看似已上线的地址。仅当用户已授权对外发布时执行发布操作；需要账号或签名操作时，先完成可独立验证的本地准备。
